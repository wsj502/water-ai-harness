模型 Provider

双协议适配：OpenAI 兼容 + Anthropic Messages。凭据只存环境变量，永不入库。

Provider 与协议
厂商协议决定请求/响应的消息格式
当前模型会话中可随时切换
Base URL智谱 Anthropic 兼容端点
API Key从环境变量 ZHIPU_API_KEY 注入
✓ 已从 DPAPI 加密存储解密注入，进程内存中存在，不落盘
协议适配说明
同一内核，两种线协议：
· Anthropic Messages：system 独立字段、tool_use/tool_result 块、x-api-key 头 —— 智谱 coding plan、Claude 官方
· OpenAI 兼容：messages 内嵌 system、tool_calls 字段、Authorization: Bearer 头 —— DeepSeek、通义、vLLM
内核内部统一为 Water 消息模型，由 Provider 适配器双向翻译（详见文章 02）。
